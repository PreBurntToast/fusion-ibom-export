# fusion-ibom-export
**Automating the .brd export from Fusion 360:** if you're working in Fusion
360's Electronics workspace, you can skip the manual File > Export step —
[PreBurntToast](https://github.com/PreBurntToast)'s
[fusion-ibom-export script](https://github.com/PreBurntToast/fusion-ibom-export)
runs from Fusion's Scripts and Add-ins dialog, exports the open board via
Fusion's Electronics API, and calls this script for you in one step.
